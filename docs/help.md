# help

Long help for `bottle help`. One file per topic in
[help/](help/). The binary prints that file, nothing else.

`bottle help` is [help/overview.md](help/overview.md).
`bottle help log` is [help/log.md](help/log.md). Schema
verbs are `bottle help schema add` →
[help/schema-add.md](help/schema-add.md).

`--help` on any command is the short usage: flags and
argument names. `help` is the page a human or a bot should
read to understand the verb.

Output is prose, not TSV. Unknown topic: exit 2.
